# 👥 HR Analytics Dashboard | Power BI

## 📌 Project Overview

This project focuses on analyzing Human Resources (HR) data using Microsoft Power BI. The objective is to transform raw employee data into meaningful business insights through interactive visualizations, KPI tracking, and workforce analysis.

The dashboard helps HR teams understand employee-related metrics, monitor workforce patterns, and support data-driven decision-making.

## 🎯 Project Objectives

- Analyze overall employee data.
- Understand workforce distribution.
- Evaluate employee demographics.
- Analyze department-wise employee distribution.
- Monitor employee performance.
- Identify important HR trends and patterns.
- Develop an interactive dashboard for HR reporting.

## 🛠️ Tools & Technologies

- **Power BI Desktop:** Dashboard development and data visualization.
- **Power Query:** Data cleaning and transformation.
- **DAX:** Measures and calculated columns.
- **Microsoft Excel:** Dataset management and preparation.
